Forecasts, for every GTA VI trophy, five quantiles of its earn rate on Exophase one week after launch, from the history of trophy-page reads before the checkpoint. A saturating logistic growth fit per trophy, blended with a log-time trend and a population model, with progression-funnel caps and a horizon-scaled spread.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
